# Mail Report (EWS / Exchange)

## 📌 A cosa serve
**Mail Report (EWS / Exchange)** è un’applicazione desktop per Windows che consente di generare **report sul numero di email ricevute e inviate** in un intervallo di date scelto.

È pensata per:
- uffici
- enti
- aziende
- professionisti IT

che utilizzano **Exchange Web Services (EWS)**.

---

## ✅ Caselle supportate
Funziona con qualsiasi provider che espone **EWS**:

- ✔ Microsoft Exchange (on-prem)
- ✔ Microsoft 365 / Office 365 *(se EWS è abilitato nel tenant)*
- ✔ Amazon WorkMail

❌ **Non funziona** con provider che espongono solo IMAP/SMTP (es. Gmail standard, alcune PEC).

---

## 💻 Requisiti
- Windows 10 / 11
- Connessione Internet
- Credenziali valide di una casella EWS

Non è necessario Python: il programma è fornito come **EXE**.

---

## 🚀 Avvio del programma
1. Apri la cartella del programma
2. Avvia `MailReportEWS.exe`

> ⚠️ Se Windows mostra *“Windows ha protetto il PC”*  
> clicca **Ulteriori informazioni → Esegui comunque**
